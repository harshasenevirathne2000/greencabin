How to create your GitHub Personal Access Token:
  1. Sign in to your GitHub account and navigate to Settings → Developer Settings → Personal Access Tokens → Tokens (classic).
  2. Click "Generate new token (classic)".
  3. Set Note to "Green Cabin Admin", check the repo (Full control of private repositories) permission scope, and generate token.
  4. Copy the generated token (starts with ghp_...), paste it into the field above, and click "Test Connection & Save"!

Wix Embed Code Generator (Full Website)

This production bundle is completely standalone, embedding Home, Bakery Menus, Catering, Platters, Outlets, Heritage, Header, Footer, and Cocon Regular Webfonts.

Simple Steps to Embed into Wix Editor:
  1. Click the "Copy to Clipboard" button below.
  2. In your Wix Editor, click + (Add Elements) → Embed Code → Embed HTML.
  3. Click Enter Code, paste the copied HTML code, and click Apply / Update.
  4. Stretch the HTML element to Full Width and click Publish!

Connect GitHub for Live Deploy

To push your updates directly to GitHub Pages from your browser, please enter your GitHub Personal Access Token once. It will be stored safely in your browser only.
